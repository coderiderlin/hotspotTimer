# 🍲 火锅涮肉计时器 (Hotpot Timer)

一个专为手机端设计的火锅涮肉与食材涮烫倒计时 Web 工具。

## 🌟 特性
- 🥩 **40+ 款食材时间表**：涵盖牛羊肉、内脏、海鲜水产、丸滑豆面、新鲜蔬菜、菌菇根茎。
- ⏱️ **队列管理**：点击菜品即可开始计时，支持多菜品同时涮烫。
- 🔔 **完成提醒**：倒计时结束变绿闪烁，配合撒彩带动效、卡通音频与设备振动。
- 👆 **手势操作**：队列卡片支持左滑删除/一键捞出。
- 🎨 **双色主题**：默认卡通亮色火锅主题，支持一键切换夜间暗色主题。

## 🛠️ 技术栈
- React 19 + TypeScript + Vite
- Tailwind CSS + Lucide Icons
- Web Audio API + Vibration API + Canvas Confetti
